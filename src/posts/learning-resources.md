If you're new to the technologies this starter uses, the learning curve can feel steep. But you don't need to master everything before you start. Learn as you go, and this starter is designed to be approachable even with minimal prior knowledge.

## Start with Markdown

Markdown is a lightweight markup language that lets you write formatted text using plain text. It's what you'll use to write your blog posts. It's simple enough to learn in an afternoon, but powerful enough for most writing needs.

- [Markdown Guide](https://www.markdownguide.org/): In-depth guide with examples
- [CommonMark Tutorial](https://commonmark.org/help/tutorial/): Interactive tutorial with exercises
- [Daring Fireball: Markdown Basics](https://daringfireball.net/projects/markdown/basics): Original Markdown documentation

You'll use Markdown immediately to write posts, so start here. The basics are enough to get you going—headings, lists, links, images, and code blocks. You can pick up the rest as you need it.

## Learn Git Basics

Git is version control software. It tracks changes to your files so you can see history, undo mistakes, and collaborate with others. It's essential for any modern development workflow, not just for this starter.

- [Git for Beginners Tutorial](https://deployn.de/en/blog/git-tutorial/): Step-by-step from installation to first project
- [freeCodeCamp Git Handbook](https://www.freecodecamp.org/news/learn-how-to-use-git-and-github-a-beginner-friendly-handbook/): In-depth beginner-friendly handbook
- [How to Use Git: A Beginner's Guide](https://realpython.com/how-to-use-git/): Practical guide with examples

Focus on the basics: `git add`, `git commit`, `git push`, and `git pull`. That's enough to get started. Branching and merging can come later when you need them.

## Set Up GitHub

GitHub is a platform for hosting Git repositories. It's where you'll store your code and collaborate with others. It's also where Netlify will deploy your site from.

- [GitHub Hello World](https://docs.github.com/en/get-started/using-github/hello-world): Learn repositories, branches, commits, and pull requests
- [GitHub for Beginners](https://github.blog/developer-skills/github/github-for-beginners-your-roadmap-to-mastering-the-github-essentials/): Roadmap to mastering GitHub essentials
- [Introduction to GitHub](https://github.com/github-education-experiences/introduction-to-github): Free course, less than an hour

Create an account, learn how to create a repository, and understand the basic workflow. That's all you need to get your site deployed.

## Try Eleventy

Eleventy is the static site generator this starter uses. It takes your templates and content and builds a static website. It's simple, flexible, and well-documented.

- [Official Getting Started](https://www.11ty.dev/docs/): Official documentation with quickstart
- [Learn Eleventy](https://learneleventy.dev/): 31-lesson course building a site from scratch
- [CloudCannon Eleventy Tutorial](https://cloudcannon.com/tutorials/eleventy-beginner-tutorial/): Six-part beginner series

The official quickstart is the best place to start. You'll have a working site in minutes. This starter gives you a head start on templates and configuration, so you can focus on customization.

## Deploy to Netlify

Netlify is a hosting platform for static sites. This starter includes a `netlify.toml` configuration file for easy deployment. It's free for personal sites and handles SSL, CDN, and automatic deployments.

- [Netlify Quickstart](https://docs.netlify.com/start/overview/): Find your fastest path to publishing
- [How to Deploy on Netlify](https://dev.to/md-mostafa-niloy/how-to-deploy-a-website-on-netlify-5fh2): Drag-and-drop and GitHub deployment options
- [Deploy from Repository](https://docs.netlify.com/start/quickstarts/deploy-from-repository/): Connect your Git repo for automatic deployments

Start with drag-and-drop deployment to see your site live. Then connect your GitHub repository for automatic deployments on push. It's magical when it works.

## Learn JavaScript as Needed

JavaScript is the programming language of the web. This starter uses it for configuration (ESM), filters, and a small amount of client-side code. But you don't need to be a JavaScript expert to use this starter.

- [The Modern JavaScript Tutorial](https://javascript.info/): From basics to advanced, detailed explanations
- [LearningJavaScript.org](https://learningjavascript.org/lessons): 25 free interactive lessons, runs in browser
- [JavaScript Tutorial 2025](https://codecan.net/javascript-tutorial-2025-complete-guide/): Complete beginner-friendly guide

Learn the basics—variables, functions, objects, arrays. That's enough to understand the configuration files and make simple customizations. Advanced JavaScript can come later if you need it.

## The Learning Path

If you're completely new to all of this, here's a suggested order:

1. Start with **Markdown**: you'll use it immediately to write posts
2. Learn **Git** basics: you'll need it to track your changes
3. Set up a **GitHub** account and learn the basics
4. Try **Eleventy** by following the official quickstart
5. Deploy to **Netlify** using drag-and-drop first, then connect GitHub
6. Learn **JavaScript** as needed for more advanced customization

Don't feel like you need to master everything before you start. You can learn as you go, and this starter is designed to be approachable even with minimal prior knowledge. The goal is to get your site live, not to become an expert in every technology first.

## Resources for Deep Dives

When you're ready to go deeper, these resources are excellent:

- [Static Site Showdown](https://staticgen.com/): Compare static site generators
- [Jamstack.org](https://jamstack.org/): Modern web development architecture
- [IndieWeb.org](https://indieweb.org/): Principles and practices of the IndieWeb

The IndieWeb community is welcoming and helpful. Don't hesitate to ask questions or share your progress. The IndieWeb is about people, not just technology.
